## Suspicious Words to Watch
*Transistor produces these incorrectly or inconsistently — flag on every episode*

- Any word containing "bism" → likely Bismyte
- "Bismarck" → Bismyte (Transistor autocorrects to the place name)
- "silvery" alone (without "barbs") → likely Cilivry
- "Phenom" / "Phenomenon" / lowercase "phenom" → Phynom Green
- "Roland" → Rolan (Transistor consistently adds a trailing 'd')
- "protobuf" / "proto puff" / "proper puff" → Pronto Puff
- "fae bud" / "fay bud" / "Faye bud" → Feybud
- "Trendle" / "Trindle" / "Trundle" → Tryndle
- "Winged Spire" / "Winged Spire" → Winged Spire
- "Lotem" / "Loedem" / "Lotum" (as in "Blade of Lotum") → Lodom
- "Sir Bo" / "Servo" / "Serbo" → Sir Beau
- Any "Orth-" marketplace mangle (Ortheor, Orthier, Ortheer, Oorthier) → Lake Orthyr
- "fear bog/books/bulgs" / "fur bulb" / "fair ball" / "Fjerbug" → Firbolg
- "Jason Calzone" / "Jaesung" / "Jayson Kelzone" → Jayson Chalzone
